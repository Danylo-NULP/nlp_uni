# Лабораторна робота №10 — NER Pipeline & Hybrid Rules

### 1. Який напрям і задача
**Напрям А:** Natural Language Inference (датасет SNLI). 
**Підзадача:** Розпізнавання доменних візуальних сутностей (кольори, одяг, тварини) в описах фотографій (Image Captions).

### 2. Який pipeline використано
Використано англомовну модель `en_core_web_sm` від `spaCy` як базовий NER. Поверх нього імплементовано гібридний шар `EntityRuler` (у файлах `src/ner_pipeline.py` та `src/ner_rules.py`).

### 3. Які rules додано
Додано три масиви патернів на основі словників:
1. `COLOR`: список кольорів (red, blue, brown...).
2. `CLOTHING`: предмети одягу (shirt, hat, pants...).
3. `ANIMAL`: види тварин (dog, cat, elephant...).

### 4. Що стало краще після hybrid layer
Базова NER-модель була абсолютно сліпою до візуальних об'єктів (Missed Domain Entities) і робила Type Errors (наприклад, визначала слово "Brown" як ім'я людини). Гібридний шар виправив обидві проблеми, дозволивши розпізнавати 100% сутностей з наших словників і усунувши хибні спрацьовування.

### 5. Головний висновок
Використання виключно "коробкових" статистичних моделей для специфічних доменів (таких як Image Captions) не має сенсу. Гібридний підхід (ML + Rules), де доменні знання інжектуються через жорсткі словникові правила перед основною моделлю, є найшвидшим і найнадійнішим способом вирішення реальних бізнес-задач витягування інформації.
