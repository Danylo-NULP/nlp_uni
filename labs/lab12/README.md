# Лабораторна робота №12 — Tool-grounded Single-Agent

### 1. Опис Use Case
Метою роботи є створення **Image Caption Quality Assistant** — автономного агента, який оцінює якість описів фотографій для датасету SNLI.
Агент повинен перевіряти, чи достатньо опис деталізований (чи має він кольори/одяг), чи містить він тварин, і чи відповідає мінімальним вимогам щодо довжини (мінімум 5 слів).

### 2. Архітектура та Інструменти (Tools)
Реалізовано систему з одним агентом (ReAct-архітектура), який замість "сліпої" генерації тексту використовує Python-функції для здобуття фактів. Усі виклики інструментів суворо фіксуються через `ToolLogger` у файл `tool_logs_lab12.jsonl`.
Реалізовано 3 інструменти:
1. `validate_caption_length`: Перевіряє кількість слів у тексті.
2. `extract_visual_attributes`: Шукає в тексті кольори та предмети одягу (на основі словників).
3. `check_animal_presence`: Визначає наявність тварин.

### 3. Базові Метрики (на 10 Test Cases)
* **Tool call success rate:** 100.0% (інструменти відпрацювали без системних збоїв).
* **Average tool calls per task:** ~2.5 (Агент комбінував інструменти для повноти аналізу).
* **Відсоток задач із корисними викликами:** 100% (інструменти дали чіткі дані, що усунуло галюцинації).
* **Зайві виклики (Unnecessary calls):** 3 з 10 (Агент продовжував викликати інструменти пошуку атрибутів для текстів з 1 слова, ігноруючи провал валідації довжини).

### 4. Аналіз Baseline vs. Agent
Базова модель (Baseline LLM), відповідаючи на запит "чи достатня довжина і чи є кольори", часто галюцинувала: вона не вміє точно рахувати слова і може вигадати колір, спираючись на ймовірності слів. 
Tool-grounded Agent повністю усунув цю проблему. Він покладався виключно на JSON-відповіді від детермінованих Python-функцій, тому його фінальні висновки були на 100% фактологічними.

### 5. Головний висновок та напрямки покращення
Агентний підхід перетворює LLM з генератора тексту на логічного контролера. Головна проблема нашої поточної архітектури — відсутність стратегії "Раннього виходу" (Early Exit). Надалі системний промпт варто доповнити жорстким правилом: "Якщо `validate_caption_length` повертає `is_valid: False`, негайно припини перевірки і надай фінальну відповідь".
