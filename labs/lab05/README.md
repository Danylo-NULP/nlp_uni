# Лабораторна робота №5 — Розподіл даних та перевірка витоків (Splits & Leakage Checks)

### 1. Мета та завдання
Метою лабораторної роботи є створення чесного, детермінованого та відтворюваного розподілу датасету SNLI (Natural Language Inference) на тренувальну, валідаційну та тестову вибірки, а також проведення перевірок на відсутність витоку даних (Data Leakage), що може штучно завищити метрики майбутньої моделі.

### 2. Стратегія розподілу
Використано **Stratified Random Split** у пропорції 80/10/10 (Train / Val / Test) із фіксованим `seed=42`. Оскільки датасет SNLI є задачею багатокласової класифікації, стратифікація по цільовій змінній (`label`) гарантує ідентичний баланс класів (entailment, contradiction, neutral) у всіх трьох сплітах.

### 3. Результати Sanity Checks
* **Баланс класів:** Ідеально збережений (розбіжність 0%).
* **Довжина текстів:** Медіанна довжина об'єднаного тексту (Premise + Hypothesis) становить 20 слів і є однаковою для всіх вибірок. Перекосів не виявлено.

### 4. Результати Leakage Checks
* **Exact Duplicates:** Виявлено незначну кількість точних дублів (що є нормою для специфіки збору SNLI, де однакові пари речень могли потрапляти до різних анотаторів).
* **Near-Duplicates:** Виявлено перетини за TF-IDF (cosine similarity > 0.95). Це збіги базових речень (Premise), до яких краудсорсери писали різні гіпотези (Hypothesis). Це специфіка датасету, а не критичний витік.
* **Template Leakage:** Службових метаданих у текстах не виявлено. Вживання слів назв класів (напр., "neutral") є частиною природної мови.
* **Fit-on-Train:** Дисципліна дотримана, векторизатор навчався виключно на тренувальній вибірці.
