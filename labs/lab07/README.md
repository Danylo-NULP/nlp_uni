# Лабораторна робота №7 — Linear SVM + Char-ngrams + Imbalance

### 1. Підзадача класифікації
**Natural Language Inference (NLI)** — багатокласова класифікація логічних відношень між двома об'єднаними реченнями (Premise + Hypothesis) на три класи: `entailment`, `contradiction`, `neutral`.

### 2. Baseline із ЛР6 для порівняння
У якості базової моделі було взято пайплайн з ЛР6: `TfidfVectorizer` (word 1-2) + `LogisticRegression`. 
* **Метрики ЛР6:** Accuracy = 0.3867, Macro-F1 = 0.3862.

### 3. Протестовані SVM-варіанти
Для побудови сильнішого класичного baseline було протестовано `LinearSVC` з різними параметрами `TfidfVectorizer`:
* **Word-level:** n-grams (1,2)
* **Char-level:** char_wb n-grams (3,5)
* **Комбінація (FeatureUnion):** word + char
* **Збалансовані ваги:** додавання `class_weight='balanced'`

### 4. Робота з дисбалансом
Аналіз показав **ідеальний баланс класів** у навчальній вибірці: `contradiction` (0.333), `entailment` (0.333), `neutral` (0.333). Через відсутність дисбалансу параметр `class_weight='balanced'` практично не змінив ваги, і метрики залишилися на рівні Accuracy = 0.3867, Macro-F1 = 0.3856.

### 5. Підбір порогу (PR-логіка)
Було реалізовано аналіз One-vs-Rest для класу `contradiction`. За бізнес-логікою (наприклад, для системи фактчекінгу) пропустити суперечність (False Negative) гірше, ніж хибно позначити нейтральне речення як суперечливе (False Positive). 
* **Обраний поріг:** `-0.3` (Recall-first).
* **Результат:** Recall для `contradiction` зріс до 0.56 (замість базових ~0.44), але ціною загального падіння Precision до 0.37.

### 6. Найкраща модель
Найкращою конфігурацією з поміж нових експериментів стала **LinearSVC (Word 1-2)**, проте вона не змогла суттєво перевершити Logistic Regression з ЛР6. Символьні n-грами (char-ngrams) не дали жодного приросту, оскільки датасет SNLI складається з чистої літературної англійської мови без друкарських помилок чи специфічного сленгу.

### 7. Що робити далі
Error Analysis вкотре підтвердив вразливість лінійних моделей до *Lexical Overlap Bias* (модель прогнозує `entailment`, якщо слова збігаються, ігноруючи суть). Лінійні моделі на базі TF-IDF повністю вичерпали свій потенціал для задачі NLI. Єдиний шлях для суттєвого покращення метрик — перехід до векторних ембеддингів (Word2Vec) або трансформерів (Sentence-BERT).
