# Лабораторна робота №11 — LLM Extraction (Schema-First)

### 1. Опис задачі (Extraction Task)
Метою роботи є витягування структурованої інформації (JSON) з неструктурованого тексту. Для нашого корпусу **SNLI (Image Captions)** була розроблена схема для видобування візуальної сцени:
* `primary_subject` (string): Головний суб'єкт (наприклад, "A man").
* `action` (string): Основна дія ("playing guitar").
* `clothing` (array of strings): Елементи одягу (["blue shirt"]).
* `location` (string): Місцезнаходження ("beach").

### 2. Архітектура Pipeline
Замість хмарних API було використано **локальну квантовану модель** `unsloth/llama-3-8b-Instruct-bnb-4bit` через бібліотеку `transformers`.
Система працює за підходом **Schema-First**:
1. **Prompt Generator:** Формує запит із жорсткою вказівкою повернути лише JSON за схемою.
2. **LLM Inference:** Локальна модель генерує текст.
3. **JSON Validator:** Скрипт очищає форматування (Markdown бекстіки) та перевіряє вихід через `jsonschema`.
4. **Repair Loop:** Якщо JSON невалідний, помилка (наприклад, "clothing is not of type array") загортається у новий промпт і відправляється моделі на виправлення (до 2 спроб).

### 3. Аналіз помилок та ефективність Repair Loop
Під час тестування локальна Llama-3 робила дві типові помилки:
1. **Parse Errors:** Додавала зайвий текст перед JSON. Вирішено за допомогою Regex-очищення на етапі валідації.
2. **Schema Type Errors:** Замість масиву для одягу (якщо він один) повертала звичайний рядок (наприклад, `"red hat"` замість `["red hat"]`). 
**Вплив Repair Loop:** Цикл виправлення показав себе блискуче. Отримавши конкретну помилку від валідатора, Llama-3 з другої спроби успішно конвертувала рядки у масиви та додавала пропущені `null` значення. Це дозволило підвищити кінцевий Valid JSON Rate практично до 100%.

### 4. Висновок
Підхід *Schema-First + Repair Loop* є критично важливим патерном для production-систем. Використання валідатора дозволяє автоматизувати виправлення галюцинацій та помилок типізації LLM, забезпечуючи надійний структурований вихід для подальшої аналітики чи збереження в БД.
