# Лабораторна робота №8 — Topic Modeling (LSA vs LDA)

### 1. Які моделі та $k$ перевіряли
Було протестовано два класичних алгоритми машинного навчання без вчителя (Unsupervised Learning):
* **LSA** (Latent Semantic Analysis на базі TF-IDF та SVD)
* **LDA** (Latent Dirichlet Allocation на базі CountVectorizer)
Для кожної моделі досліджено кількість тем $k = 5, 8, 10$.

### 2. Яка модель дала кращі теми
Безперечним лідером для датасету SNLI стала модель **LDA (k=10)**. Вона змогла чітко розпізнати візуальні сюжети з фотографій: гру у футбол, музичні гурти, дитяче дозвілля та описи одягу. Модель LSA не впоралася із завданням, згенерувавши велику кількість дубльованих тем, зміст яких зводився до шаблонних "люди йдуть по вулиці".

### 3. Головний висновок по корпусу
Датасет SNLI має гігантський **лексичний шум шаблонних конструкцій** (слова *man, woman, person, walking, wearing* зустрічаються майже скрізь). Це доводить, що метрика **Coherence Score не завжди відображає якість**: LSA отримала вищий бал (0.37) лише через математичну частоту цих шаблонних слів, тоді як LDA (0.34) знайшла справжні сенсові кластери. 

### 4. Плани на покращення
Для оптимізації тематичного моделювання подібних корпусів (Image Captions) необхідно застосовувати лінгвістичну фільтрацію: видаляти загальні суб'єкти через POS-теги, залишаючи алгоритмам лише унікальні об'єкти та дії.
