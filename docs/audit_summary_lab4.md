# Audit Summary: Lab 4 (Rule-based IE)

## 1. Загальна інформація
* **Напрям:** Rule-based Information Extraction (витяг сутностей за детермінованими правилами).
* **Датасет:** Англомовний корпус SNLI (очищена версія `processed_v2.csv`).
* **Цільові сутності:** QUANTITY (числа, групи), COLOR (базові кольори), LOCATION (типи локацій сцен).

## 2. Метрики Precision на Gold Subset (Автоматичний розрахунок)
Тестування за допомогою еталонного набору даних `lab4_gold_ie.csv` зафіксувало наступні показники точності:
* **QUANTITY:** `1.00` (4 правильних з 4 знайдених)
* **COLOR:** `1.00` (3 правильних з 3 знайдених)
* **LOCATION:** `1.00` (3 правильних з 3 знайдених)

*Примітка:* Максимальна точність на Gold Subset пояснюється тим, що тестові речення містять чіткі ізольовані сутності без накладання мовного шуму.

## 3. Лінгвістичний аналіз помилок (False Positives) на базі Edge Cases
Під час стрес-тестування за допомогою розширеного набору `tests/ie_edge_cases.jsonl` зафіксовано 2 випадки хибних спрацювань системи:

1. **Фраза:** `A white-collar worker.`
   * *Помилкове витягування:* `COLOR = white`
   * *Причина:* Regex зорієнтувався на слово `white`, проігнорувавши складену дефісну структуру соціологічного терміну.
   * *Запобіжник:* Необхідно розширити негативний перегляд вперед для врахування дефісів у прикметниках.

2. **Фраза:** `A one-way street.`
   * *Витягування:* `LOCATION = street`
   * *Причина:* Правило для QUANTITY успішно заблокувало слово `one` через дефіс, проте іменник `street` було витягнуто в якості локації. Це часткове False Positive, оскільки слово входить до складу складного прикметника назви типу вулиці, хоча семантично локація залишається правильною.

## 4. Остаточне архітектурне рішення
Розроблений правиловий модуль демонструє високу початкову точність, проте потребує лінгвістичного контексту. Ухвалено рішення: на наступному етапі поєднати Regex-патерни з POS-фільтрами (Lab 3) для блокування сутностей, що виражені невластивими частинами мови (наприклад, відсікання кольорів та локацій, якщо вони є частиною дефісних прикметників).
